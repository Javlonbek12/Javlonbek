## Этап 0 — Каркас проекта

### Что сделано
- Next.js 16 + TypeScript + Tailwind CSS 4 + shadcn/ui (кнопка `Button`, тема).
- Пустая страница «Assistant» на русском, тексты интерфейса — в словаре `lib/i18n/ru.ts`.
- Prisma 7 + PostgreSQL 16; `docker-compose.yml` поднимает базу для разработки; пустая схема и seed-скрипт.
- Проверка переменных окружения (`lib/env.ts`), `.env.example` с комментариями на русском.
- `/api/health` — проверка, что приложение и база работают.
- PWA: manifest, иконки-заглушки, service worker (страница открывается без интернета).
- Vitest + Testing Library, ESLint + Prettier, typecheck. Тесты: 9 штук (i18n, env, главная страница, интеграционный тест API с базой).
- GitHub Actions: lint + typecheck + test + build на каждый push.
- README.md, STATUS.md, docs/DECISIONS.md.

## Этап 1 — Ядро: вход, роли, бот-скелет, уведомления

### Что сделано
- Таблицы: User, Invite, Notification, UserSettings, ActivityLog (миграция `core`).
- Вход через Telegram Login Widget (с проверкой подписи), сессия в httpOnly-cookie. Первый вошедший — OWNER, остальные — только по приглашению.
- «Вход для разработки» для проверки на своём компьютере без домена.
- Приглашения: ссылка на сайт и ссылка на бота, одноразовые, 7 дней, отмена. Страница «Команда»: участники, роли, смена роли (OWNER), приглашения.
- Бот (grammY): `/start` (привязка или регистрация по коду), `/help`; режимы long polling (`npm run bot:dev`) и webhook (`/api/telegram/webhook`, `npm run bot:set-webhook`).
- Сервис `notify()`: уведомление в приложении + в Telegram; страница уведомлений (счётчик непрочитанных, «прочитано»), настройки (Telegram вкл/выкл, тихие часы, типы уведомлений, часовой пояс), тестовое уведомление.
- Меню: снизу на телефоне, слева на компьютере; пункты берутся из реестра модулей с учётом роли.
- Журнал действий: вход новых людей, приглашения, смена ролей.
- Тесты: 79 (роли и права, приглашения, подпись Telegram, сессии, тихие часы, уведомления, бот, API входа/выхода/webhook, сквозной сценарий этапа).

### Что проверить вручную
См. отчёт этапа 1 в чате.
