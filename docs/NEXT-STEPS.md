## Регулярно

- Раз в неделю скачивать бэкап к себе: Actions → Server → `backup-export` (`docs/SETUP-SERVER.md`, раздел 10).
- Раз в месяц смотреть расход ИИ: карточка «Расход ИИ за …» в «Настройках» (видит владелец) и Actions → Server → `usage`.
- Если что-то сломалось: Actions → Server → `status` и `logs`, затем пришлите мне вывод.
