# Что делать дальше: пошаговый план для владельца

Шаги идут по порядку: следующий начинайте, когда закончен предыдущий.
Галочкой ☐ отмечайте сделанное. Если где-то застряли — пришлите мне текст ошибки или скриншот.

---

## Шаг 1. Запустить Assistant у себя на компьютере (≈ 30 минут)

Зачем: посмотреть и потрогать всё до покупки сервера.

> ⚠️ Вся новая работа пока лежит в ветке `claude/amazing-pascal-fw0ojx`, в основной ветке `main`
> её ещё нет. Если вы просто скачали проект, у вас старая версия — скорее всего, поэтому он не
> запускался. Команда из пункта ☐ 2 переключает на нужную версию.

☐ 1. Установите **Node.js 22**, **Docker Desktop** и **Git** (ссылки — в `README.md`). Откройте Docker Desktop.

☐ 2. В терминале, в папке проекта:
```bash
git fetch
git checkout claude/amazing-pascal-fw0ojx
git pull
```

☐ 3. Если файла `.env` ещё нет: `cp .env.example .env`, откройте его и впишите в `SESSION_SECRET`
любую строку из 32+ символов. `ALLOW_DEV_LOGIN=true` оставьте.

☐ 4. По очереди:
```bash
npm install
docker compose up -d
npm run db:migrate
npm run db:seed
npm run dev
```

☐ 5. Откройте http://localhost:3000 → «Вход для разработки» → войдите (первый вошедший — владелец).
Посмотрите разделы: Сегодня, Задачи, Встречи, Команда, Планограммы.

☐ 6. Если что-то из пунктов 2–5 выдало ошибку — **остановитесь и пришлите мне текст ошибки**.

## Шаг 2. Подготовить аккаунты и ключи (≈ 30 минут, можно параллельно с шагом 1)

☐ 1. **Telegram-бот:** в Telegram откройте @BotFather → `/newbot` → сохраните **токен** и **имя бота**.

☐ 2. **Ключ Claude (ИИ):** https://console.anthropic.com → зарегистрируйтесь → пополните баланс →
API Keys → создайте ключ и сохраните его. Без ключа бот работает, но не разбирает фразы на задачи.

☐ 3. Храните токен и ключ как пароли: никому не пересылайте и не вставляйте в код или GitHub.

## Шаг 3. Проверить бота и ИИ на своём компьютере (≈ 15 минут)

☐ 1. Впишите в `.env`: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME`, `ANTHROPIC_API_KEY`.

☐ 2. В отдельном окне терминала: `npm run bot:dev`. Откройте бота в Telegram → `/start`.

☐ 3. Напишите боту: «Завтра подготовить отчёт» → должна прийти карточка → «✅ Сохранить» → задача
появится на сайте.

☐ 4. Проверка ИИ на 25 фразах: `npm run test:ai` (стоит несколько центов). Пришлите мне результат.

> Голосовые на компьютере распознаются «заглушкой». Настоящее распознавание заработает на сервере (шаг 6).

## Шаг 4. Перенести работу в основную ветку `main` (≈ 5 минут)

Нужно, чтобы сервер обновлялся сам. Напишите мне **«создай pull request»** — я подготовлю его.
Затем на GitHub откройте его, дождитесь зелёной галочки проверок и нажмите **Merge pull request**.

☐ Ветка слита в `main`.

## Шаг 5. Купить сервер и домен (≈ 1 час, включая ожидание)

☐ 1. **VPS** с Ubuntu 24.04: 2 ядра, **8 ГБ памяти** (с 4 ГБ — без своего распознавания голоса), 40 ГБ диска.

☐ 2. **Домен или поддомен** (например `assistant.ваша-компания.uz`) → A-запись на IP сервера.

☐ 3. В @BotFather: `/setdomain` → ваш бот → ваш домен.

## Шаг 6. Установить на сервер (≈ 30 минут)

☐ 1. Ключ на сервере и секреты на GitHub — `docs/SETUP-SERVER.md`, способ 1, шаги 1.1–1.2.

☐ 2. Напишите мне **«секреты готовы»** — я запущу установку и проверю результат.
(Или сами: Actions → Server → Run workflow → `setup`.)

☐ 3. После установки: @BotFather → `/setdomain` и первый вход на сайт (шаг 1.4).

## Шаг 7. Проверить всё на сервере (≈ 1 час)

☐ 1. Вход через Telegram на сайте, `/start` в боте, задача текстом и **голосом** (раздел 9 `docs/SETUP-SERVER.md`).

☐ 2. Пригласите тестового сотрудника, поставьте ему задачу → уведомление и кнопки утверждения в Telegram.

☐ 3. Создайте встречу через 20 минут → напоминание за 15 минут.

☐ 4. Планограмма: создать с автозаполнением → утвердить → скачать PPTX и PDF → открыть ссылку для
мерчендайзеров на телефоне.

☐ 5. Прайс-лист: загрузить Excel с новыми ценами → «что изменится» → утвердить.

☐ 6. Бэкап: `./scripts/backup.sh` → в `~/assistant-backups` появились файлы.

☐ 7. Сторож: `docker compose -f docker-compose.prod.yml stop worker` → через ~10 минут вам приходит
сообщение → `docker compose -f docker-compose.prod.yml up -d`.

Всё, что не работает, — пришлите мне (что делали и что увидели). Список того, что ещё не
проверялось вживую, — раздел 2 в `docs/BACKLOG.md`.

## Шаг 8. Наполнить данными и пригласить команду

☐ 1. **SKU:** Excel с колонками код, бренд, название, формат, обязательный, новинка →
«Планограммы» → «SKU» → «Импорт».

☐ 2. **Цены:** Excel с колонками код, цена → «Прайс-листы».

☐ 3. **Картинки пачек:** в карточке каждого SKU → «Загрузить картинку».

☐ 4. Пришлите мне **логотип** и **фирменный шаблон PPTX** — я подключу их.

☐ 5. Уберите в архив тестовые SKU («SKU-TEST-…»), если загружали пробные данные.

☐ 6. «Команда» → пригласите руководителей и сотрудников; дайте им `docs/USER-GUIDE.md`.
