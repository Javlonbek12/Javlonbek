- 2026-10-26 — После этапа 8 — Раздел «Распределение POSM» (`/distribution`, модуль `modules/distribution`). Повторяет модель файла заказчика «POSM Distribution by Region»: каждый POSM идёт на отмеченные типы оборудования; доля региона — его оборудование этих типов (или их слоты); округление вниз, остаток и резерв — на центральном складе; доля Ташкента делится между TSM по их оборудованию, остаток — на складе Ташкента. Данные приходят загрузкой этого же Excel (`/distribution/import`, владелец и руководители): оборудование заменяется, позиции POSM обновляются по названию, отгрузки сохраняются. Связь с планограммами: каждому из 12 типов соответствует оборудование библиотеки (DISPLAY_XL_POSI … DISPLAY_S_MW); из его планограммы (утверждённой, иначе последней) берутся цены на полках, и потребность в ценниках считается как оборудование × позиции с этой ценой; для ценника можно выбрать базу «По планограмме». Склад и отгрузки: доступно = на складе + заказано; отгрузки записываются по позиции или целой накладной региона/TSM, видно, куда сколько уехало против плана. Выводы на «Обзоре» считаются кодом (дефицит по норме, типы без POSM категории, мало штук на единицу, заказ считали не на то количество, ценники против планограмм, склад Ташкента без TSM). Раздел включается в «Настройки → Роли» («Распределение POSM»); по умолчанию — у руководителей. Отгрузки записывают все, у кого есть раздел; удалить запись может её автор или руководитель.
