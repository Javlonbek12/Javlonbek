Прогресс = доля DONE среди неотменённых задач плана и всех вложенных планов; в командный план попадают только командные задачи. Редактирование и удаление планов пока не сделаны.

- 2026-10-04 — Этап 3 — Без ключа ИИ бот не ломается: сообщение превращается в одну задачу, которую можно поправить кнопками.

Так не нужно хранить сотни отдельных расписаний, а смена часового пояса или времени дайджеста работает сразу.
